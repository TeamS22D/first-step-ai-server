| 뜻 | 개발한 소프트웨어나 서비스를 실제 사용자가 이용할 수 있는 환경(서버)에 배포하고 적용하는 것. |
| 예문 | 방금 수정된 기능 디플로이 완료했습니다. 확인 부탁드립니다. |

| 용어 | Production |
| --- | --- |
| 뜻 | 실 서비스가 운영되고 있는 실제 환경. '운영 환경'이라고도 함. |
| 예문 | 프로덕션 환경에서 버그가 발생하면 절대 안 됩니다. |

| 용어 | Staging |
| --- | --- |
| 뜻 | 운영 환경(프로덕션)과 거의 동일하게 구축한 테스트 환경. 배포 전 최종 검증 단계. |
| 예문 | 스테이징 서버에서 먼저 테스트해보고 이상 없으면 배포합시다. |

| 용어 | Rollback |
| --- | --- |
| 뜻 | 업데이트나 배포 후 문제가 생겼을 때, 이전의 안정적인 버전으로 되돌리는 작업. |
| 예문 | 긴급 장애가 발생해서 어제자 버전으로 롤백 처리했습니다. |

| 용어 | API (Application Programming Interface) |
| --- | --- |
| 뜻 | 서로 다른 소프트웨어나 시스템이 정보를 주고받을 수 있도록 미리 정의된 통신 규칙 또는 수단. |
| 예문 | 날씨 정보를 가져오기 위해 외부 날씨 API를 연동했습니다. |

| 용어 | Legacy |
| --- | --- |
| 뜻 | 과거에 개발되어 현재까지 사용되고 있지만, 기술적으로 낡거나 유지보수가 어려운 기존 시스템. |
| 예문 | 레거시 시스템을 걷어내고 신규 시스템으로 마이그레이션해야 합니다. |

| 용어 | Migration |
| --- | --- |
| 뜻 | 데이터, 소프트웨어, 시스템 등을 기존 환경에서 새로운 환경으로 이전하는 작업. |
| 예문 | 다음 주 주말에 DB 서버 마이그레이션 작업이 예정되어 있습니다. |

| 용어 | Code Freeze |
| --- | --- |
| 뜻 | (주로 서비스 정식 출시나 대규모 업데이트 직전) 안정성을 위해 코드 수정을 임시로 중단하는 것. |
| 예문 | 런칭 전까지 코드 프리즈 상태이니, 기능 추가는 불가능합니다. |

| 용어 | Roadmap |
| --- | --- |
| 뜻 | 프로젝트나 제품의 미래 계획을 시각적으로 표현한 청사진. 언제, 무엇을, 왜 할 것인지 담음. |
| 예문 | 우리 제품의 3개년 로드맵을 다시 그려봐야 합니다. |

| 용어 | Milestone |
| --- | --- |
| 뜻 | 프로젝트 진행 과정에서 중요한 단계별 목표나 중간 기점. |
| 예문 | 이번 주 마일스톤은 '1차 시안 완성'입니다. |

| 용어 | Go-to-Market (GTM) |
| --- | --- |
| 뜻 | 제품이나 서비스를 시장에 성공적으로 출시하기 위한 모든 전략 (타겟, 채널, 마케팅, 가격 등). |
| 예문 | 신제품 GTM 전략 보고서 다음 주까지 제출해 주세요. |

| 용어 | Persona |
| --- | --- |
| 뜻 | 서비스나 제품의 핵심 타겟 사용자를 대표하는 가상의 인물. (이름, 나이, 직업, 니즈 등을 구체적으로 설정) |
| 예문 | 우리 서비스의 메인 페르소나 '김대리'의 입장에서 생각해봅시다. |

| 용어 | Customer Journey Map (고객 여정 지도) |
| --- | --- |
| 뜻 | 고객이 서비스를 인지하고, 사용하고, 이탈하기까지의 전 과정을 시각화하여 경험과 감정을 분석하는 맵. |
| 예문 | 고객 여정 지도를 그려보니 구매 단계에서 이탈이 가장 많네요. |

| 용어 | A/B Test |
| --- | --- |
| 뜻 | A안과 B안 두 가지 시안을 만들어, 어떤 것이 더 좋은 성과(e.g., 클릭률, 전환율)를 내는지 비교 테스트하는 방식. |
| 예문 | 구매 버튼 색상을 두고 A/B 테스트를 진행했습니다. |

| 용어 | Scope |
| --- | --- |
| 뜻 | 업무나 프로젝트의 범위. |
| 예문 | 이번 프로젝트는 스코프가 너무 방대해서 기간 내에 끝내기 어렵습니다. |

| 용어 | OKR (Objective and Key Results) |
| --- | --- |
| 뜻 | '목표(Objective)'와 이 목표를 달성했는지 측정하는 '핵심 결과(Key Results)'로 구성된 성과 관리 프레임워크. |
| 예문 | 이번 분기 우리 팀 OKR은 '신규 유저 유입 10만 명 달성(KR)'으로 정했습니다. |

| 용어 | Retention |
| --- | --- |
| 뜻 | (고객) 유지율. 특정 기간 동안 서비스를 계속 이용하는 고객의 비율. |
| 예문 | 신규 유입도 중요하지만, 기존 고객 리텐션을 높이는 방안도 고민해야 합니다. |

| 용어 | Churn Rate |
| --- | --- |
| 뜻 | (고객) 이탈률. 특정 기간 동안 서비스를 그만두거나 이탈한 고객의 비율. |
| 예문 | 우리 서비스의 천 레이트가 높아지고 있어 원인 분석이 시급합니다. |

| 용어 | Conversion (CVR) |
| --- | --- |
| 뜻 | 마케팅 활동을 통해 유입된 고객이 회원가입, 구매 등 의도한 행동을 완료하는 비율. |
| 예문 | 광고 소재를 바꿨더니 전환율이 2%p 상승했습니다. |

| 용어 | Dashboard |
| --- | --- |
| 뜻 | 여러 데이터를 한눈에 파악할 수 있도록 시각화(차트, 그래프 등)하여 모아둔 현황판. |
| 예문 | 일일 매출 현황은 이 대시보드에서 실시간으로 확인 가능합니다. |

| 용어 | Raw Data |
| --- | --- |
| 뜻 | 아무런 가공도 거치지 않은 원본 데이터. |
| 예문 | 분석을 시작하기 전에 먼저 로우 데이터부터 확보해야 합니다. |

| 용어 | Insight |
| --- | --- |
| 뜻 | 데이터 분석이나 현상 관찰을 통해 얻게 되는 깊이 있는 통찰이나 핵심적인 의미. |
| 예문 | 고객 인터뷰를 통해 새로운 비즈니스 인사이트를 얻었습니다. |

| 용어 | Metrics |
| --- | --- |
| 뜻 | 성과를 측정하기 위한 구체적인 지표들. (e.g., 방문자 수, 체류 시간, 전환율 등) |
| 예문 | 이번 캠페인의 성공 여부를 판단할 핵심 메트릭스를 정합시다. |

| 용어 | Organic |
| --- | --- |
| 뜻 | 광고비 등 인위적인 비용 지출 없이, 검색 엔진 최적화(SEO)나 콘텐츠를 통해 자연적으로 발생하는 유입. |
| 예문 | 오가닉 유입이 꾸준히 늘고 있다는 것은 매우 긍정적인 신호입니다. |

| 용어 | Paid |
| --- | --- |
| 뜻 | 광고비를 지불하고 매체를 통해 인위적으로 발생시키는 유입. (e.g., 키워드 광고, 배너 광고) |
| 예문 | 이번 달은 페이드 마케팅 예산을 평소보다 두 배로 늘렸습니다. |

| 용어 | SEO (Search Engine Optimization) |
| --- | --- |
| 뜻 | 검색 엔진 최적화. 사용자가 검색엔진(네이버, 구글 등)에서 특정 키워드를 검색했을 때, 우리 콘텐츠가 상위에 노출되도록 하는 작업. |
| 예문 | SEO 작업을 통해 블로그 방문자 수를 늘릴 계획입니다. |

| 용어 | CPC (Cost Per Click) |
| --- | --- |
| 뜻 | 클릭당 비용. (온라인 광고) 사용자가 광고를 1회 클릭할 때마다 지불하는 비용. |
| 예문 | 이 키워드는 경쟁이 심해서 CPC가 너무 비싸네요. |

| 용어 | CTR (Click Through Rate) |
| --- | --- |
| 뜻 | 클릭률. 광고가 노출된 횟수 대비 클릭이 발생한 횟수의 비율. |
| 예문 | 광고 소재를 매력적으로 바꿔서 CTR을 높여야 합니다. |

| 용어 | Man-Month (M/M) |
| --- | --- |
| 뜻 | 맨먼스. '한 사람이 한 달 동안 일하는 양'을 나타내는 프로젝트 투입 공수(시간, 비용) 측정 단위. |
| 예문 | 이 프로젝트는 총 10 M/M가 소요될 것으로 예상됩니다. |

| 용어 | Deadline |
| --- | --- |
| 뜻 | 업무를 완료해야 하는 최종 마감 기한. |
| 예문 | 보고서 데드라인이 내일 오전 9시까지니 서둘러주세요. |

| 용어 | On-track |
| --- | --- |
| 뜻 | 프로젝트나 업무가 기존 계획대로 순조롭게 진행되고 있음. |
| 예문 | 다행히 모든 일정이 온트랙으로 진행 중입니다. |

| 용어 | Pending |
| --- | --- |
| 뜻 | (주로 의사결정이나 업무가) 보류되거나 지연되고 있는 상태. |
| 예문 | 그 건은 대표님 승인이 펜딩되어서 아직 진행을 못 하고 있습니다. |

| 용어 | Quarter |
| --- | --- |
| 뜻 | 1년을 4등분 한 '분기'. (1Q: 1~3월, 2Q: 4~6월 등) |
| 예문 | 3쿼터(3Q) 실적이 예상보다 저조해서 비상입니다. |

| 용어 | Hard copy |
| --- | --- |
| 뜻 | 컴퓨터 파일(소프트 카피)이 아닌, 종이로 출력된 실물 문서. |
| 예문 | 계약서는 반드시 날인된 하드 카피로 보관해야 합니다. |

| 용어 | Soft copy |
| --- | --- |
| 뜻 | 종이 문서(하드 카피)와 반대로, 이메일이나 파일 형태로 존재하는 전자 문서. |
| 예문 | 발표 자료는 소프트 카피로 먼저 공유 부탁드립니다. |

| 용어 | Onboarding |
| --- | --- |
| 뜻 | 신규 입사자가 조직과 업무에 원활하게 적응할 수 있도록 지원하고 교육하는 과정. |
| 예문 | 이번 주에 신규 입사자 온보딩 프로그램이 예정되어 있습니다. |

| 용어 | WBS (Work Breakdown Structure) |
| --- | --- |
| 뜻 | 업무 분업 구조. 프로젝트의 전체 업무를 세부적인 작업 단위로 쪼개어 구조화한 목록. |
| 예문 | WBS를 보니, 제가 맡아야 할 업무가 명확해졌습니다. |

| 용어 | Review |
| --- | --- |
| 뜻 | (성과 평가 외에도) 작업물(기획안, 디자인 시안, 코드 등)을 검토하고 피드백을 주고받는 과정. |
| 예문 | 기획안 1차본 완성했으니, 리뷰 부탁드립니다. |

| 용어 | R&R (Role & Responsibility) |
| --- | --- |
| 뜻 | 역할과 책임. 조직이나 프로젝트 내에서 각 구성원이 맡은 역할과 그에 따른 책임을 명확히 규정하는 것. |
| 예문 | 이번 프로젝트는 R&R이 불분명해서 자꾸 업무가 꼬이는 것 같습니다. |

| 용어 | Best Practice |
| --- | --- |
| 뜻 | (특정 업무를 수행하는) 가장 효율적이고 성공률이 높은 모범 사례 또는 표준 방식. |
| 예문 | 경쟁사들의 사례를 참고해서 우리만의 베스트 프랙티스를 만들어봅시다. |
