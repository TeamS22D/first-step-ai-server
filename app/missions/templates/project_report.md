# 프로젝트 완료 보고서

프로젝트 완료 보고는 프로젝트가 계획된 목표와 요구사항을 충족했음을 공식적으로 문서화 하는 것

## 착수보고

---
프로젝트 작업 시작을 알리는 보고서

- 프로젝트의 목적
- 범위
- 일정
- 예산
- 주요 이해 관계자
- 리소스
- 등...

사업계획서 작성과 함께 실시

## 완료 보고 

---
진행 중일 때 작성되는 보고서

- 프로젝트의 진행 상황
- 성과
- 문제점
- 해결책 

주요 관계자들이 프로젝트의 **현재 상황**을 이해하고, 필요한 조치를 할 수 있게끔 

주로 설계가 끝나고 실시함

프로젝트 후에 작성되는 보고서

- 배운 교훈
- 등... 을 요약

오픈 전후로 실시하며, 고객과 협의하여 시기는 유동적
