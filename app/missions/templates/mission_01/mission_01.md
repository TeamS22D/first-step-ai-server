### 프로젝트 개요:
스마트홈 기능을 100% 활용하고, 사용자 편의성에 최적화된 IoT 제어 앱을 개발하는 프로젝트
### 추진 배경:
스마트홈 기기 수요와 종류는 증가하고 있으나, 다양한 기기를 통합 제어할 수 있는 맞춤형 서비스가 부족하다고 판단하여 앱 개발을 추진함.
### 목표:
사용자 맞춤형 IoT 제어 기능 구현

## 📌 프로젝트 수행 과정
### 1. 문제 정의 및 아이디어 도출
스마트홈 기기 수요는 증가하고 있지만 이를 통합 관리하는 앱이 부재한 상황을 확인하여,

사용자가 여러 기기를 한 번에 제어할 수 있는 앱 필요성을 도출함.
### 2. 기획 및 설계
각 스마트홈 기기를 개별적으로 제어할 수 있는 핵심 기능 기획

알림, 자동화, 사용자 계정 등 부가 기능 분리 설계

사용성 중심의 UI/UX 구조화
### 3. 구현
React Native / Expo, Flutter 기반으로 iOS/Android 크로스 플랫폼 앱 개발

주요 제조사 스마트홈 기기 API 연동 수행
### 4. 테스트 및 개선
실제 스마트홈 거주자를 대상으로 베타 테스트 진행
피드백 기반 UI/UX 개선
일부 기기 연결 안정성 문제 확인하여 보완 작업 진행
